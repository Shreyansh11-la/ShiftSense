
# Rider Earnings Tracker

An offline-first earnings intelligence platform for delivery riders in India.

## The Problem

Delivery platforms show riders their gross earnings, but riders often
don't know how much they actually earn after fuel, maintenance,
vehicle expenses and unpaid waiting time.

## Our Solution

Rider Earnings Tracker helps delivery partners understand their
true earnings and make better decisions about their work.

## Planned Features

- Shift tracking and order management
- Real earnings calculations after expenses
- Per-order profitability analysis
- Best and worst working-hour insights
- Personal minimum-order recommendations
- Multi-platform earnings tracking
- Screenshot-based order analysis
- Hindi and English support
- Offline access and installable PWA
- Monthly income statements

## Technology Stack

- Next.js
- React
- Tailwind CSS
- Dexie.js / IndexedDB
- Recharts
- Git and GitHub
- Vercel

## Project Status

Currently in Milestone 0: Foundation and real-rider
problem validation.

## Privacy

Rider data stays on the user's device by default.
No bank, UPI or Aadhaar information is required.
